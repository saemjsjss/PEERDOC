# AFFIDAVIT — 5.2 Affidavit Coverage

Section: [[Section 5 - Global Cross-Checks]]
Subsection: 5.2 Affidavit Coverage

On a name mismatch (e.g. a spelling difference) the engine checks the Affidavit.
Affidavit notarised, explicitly states both spellings are the "same person", and matches the student / parent -> PASS.
No Affidavit covers the mismatch -> FAIL, except where the rule itself makes a mismatch a FLAG ([[ACAD-04]]): there it stays FLAG.
