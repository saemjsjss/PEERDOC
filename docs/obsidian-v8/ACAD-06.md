# ACAD-06 — Registration

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.8 ACADEMIC CERTIFICATES

SSC and HSC carry the same board registration number; only the session after "/" differs (1910534278/2020-21 and 1910534278/2022-23). Two reliably read numbers that differ -> FLAG. A number read with low confidence, or not found -> PASS (not checked). Only when both an SSC and an HSC document are present. *(approved)*
