# BIRTH-03 — DOB

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.3 BIRTH CERTIFICATE (the student's only)

PASS / FAIL against the Passport DOB. Bangla certificate with English translation: only the year is compared. English certificate (old BDR Form-3, new bilingual bdris.gov.bd): the full date must match. A different year FAILs even across New Year. A low-confidence date PASSes only if it equals the passport date exactly; if it differs -> FLAG. On the old Form-3 the filled square between month and year (`25 | 02 | ■ | 2002`) is skipped.
