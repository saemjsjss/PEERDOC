# BIRTH-04 — BRN

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.3 BIRTH CERTIFICATE (the student's only)

BRN must start with the birth year. Mismatch (e.g. old 13/16-digit format) -> FLAG, never FAIL.
