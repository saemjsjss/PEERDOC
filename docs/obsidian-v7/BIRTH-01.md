# BIRTH-01 — Format

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.3 BIRTH CERTIFICATE (the student's only)

if Bangla, must have an English translation. Missing -> FAIL. A bilingual certificate (Bangla and English on the same page, e.g. BDRIS) passes without a translation page when its English side gives the child's name, date of birth, father's name and mother's name; if any of them is not read -> FLAG. *(approved)*
