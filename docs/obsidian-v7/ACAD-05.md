# ACAD-05 — Notary

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.8 ACADEMIC CERTIFICATES

every academic certificate and transcript must be notarised (Section 0): the notary's red seal AND "Notary Public" / "Advocate". Missing -> FAIL; can't be confirmed -> FLAG. The e-Apostille page itself needs no notarisation. *(approved)*
