# BANK-05 — Currencies

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.5 BANK SOLVENCY & STATEMENT (BANK-01..03: one result per solvency letter)

the solvency letter must state the balance in USD and in BDT, written next to the currency ("USD 19,338.09", "BDT. 2,407,592.52") or in a table column headed by it ("Balance (USD)"). An exchange rate ("1 USD = 123.70") is not an amount. The figures are not checked. Either currency missing -> FAIL; only finding it matters, not the OCR confidence. *(approved)*
