# ACAD-06 — Registration

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.8 ACADEMIC CERTIFICATES (SSC / HSC: secondary / higher secondary school certificates;

the SSC and HSC carry the same board registration number; only the session after "/" differs (1910534278/2020-21 and 1910534278/2022-23). Two reliable numbers that differ -> FLAG. A number that is unreliable or not found is not checked (Section 0). Runs only when both an SSC and an HSC document are present. *(approved)*
