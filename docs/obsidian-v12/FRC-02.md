# FRC-02 — Identity

Section: [[Section 4 - Document-Specific Rules]]
Subsection: 4.4 FAMILY RELATIONSHIP CERTIFICATE (FRC)

the table must have a row whose relation is SELF or a word for the applicant themself (HIMSELF, HERSELF, MYSELF, ONESELF, APPLICANT, STUDENT, CANDIDATE), with a name matching [[StudentRef]]. An "Applicant Name:" line under the table counts as an APPLICANT row. No such row in a reliably read table -> FAIL. *(approved)*
